Activity Rings

Inspired by Apple Watch: concentric circular arcs, each measuring a different dimension. The outer ring wraps innermost on completion. Rings animate on mount with a staggered delay (outer first). Each ring is independently interactive — hover reveals the dimension label and value.

Effect Hierarchy & Usage Rules
✅ Use glass when
The card floats over a rich background (mesh, image, color band). The playbook landing hero, the ring overlay panel, drill-down sidebars.
🚫 Avoid glass when
The background is flat white or --surface. The content area is data-dense (matrix, tables). Both parent + child are glass.
✅ Use gradient cards when
Highlighting one featured function per screen, a CTA banner, or a "New / Sunrise" callout tile. Max 1 solid gradient card visible at a time.
✅ Use glow borders when
A card is the currently selected drill-down item, a filter chip is active, or a row is in warning state. Never on hover — elevation handles that.

Motion & Interaction

Transitions are purposeful and brief. Use easing that feels physical: ease-out for entering elements (they decelerate into place), ease-in for exiting. All motion respects prefers-reduced-motion.

Ring mount animation
stroke-dashoffset: circumf → target
Duration: 600ms

Stagger: 0 / 120ms / 240ms

background + color transitions

Reduced motion override
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
All motion collapsed to 0.01ms. Functional state (open/close) must still work visually without animation.

Iconography

Use 20×20 or 24×24 SVG icons, 2px stroke, stroke-linecap and stroke-linejoin both round. No filled icons. Color from tokens only. Heroicons or Lucide are recommended source libraries.
